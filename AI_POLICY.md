# AI policy

We support using AI tools, including large language models, when contributing to Z-Wave JS projects. You are responsible for every contribution you submit. Maintainers are responsible for every contribution they merge and release. We hold all contributions to the same high standard.

Maintainers dedicate their time and expertise to reviewing contributions. AI-generated content that you have not personally reviewed and understood wastes that time and will not be accepted.

## Autonomous agents

**We do not allow autonomous agents to contribute to Z-Wave JS projects.** We will close pull requests or issues that we believe were created autonomously. We may mark automated comments as spam. This rule also applies to contributions that bypass the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. Do not let tools post unreviewed content on your behalf. Keep responses to the minimum needed to communicate your intent. We may hide comments that appear to be unreviewed AI output.

When you open a pull request, you must be able to explain the proposed changes in your own words. This requirement covers the pull request description and responses to questions. You must review any AI-generated summary for technical accuracy.

**Do not use AI to generate the substance of answers to maintainers' questions.** You must understand and be able to explain your own work. You may use AI to improve grammar or clarity.

If you include context from an AI interaction in a comment, put it in a quote block and disclose its source. Add your own explanation of its relevance and implications. Do not share long excerpts.

## Non-native English speakers

AI can help people communicate in a language that is not their native language. You may use AI to improve the grammar or clarity of text you wrote. If you use AI for translation, make sure the translation accurately reflects your intent. You can include your original text in a details block to show your work, help maintainers verify the translation, and keep the conversation readable.

## Code and documentation contributions

AI can help write code and documentation. Every contribution requires a human who understands the work produced by AI.

You must review and understand every change before submission. You must be able to explain every code and documentation change in a pull request. We will close pull requests that appear to contain unreviewed AI output.

## Maintainer use of AI

Z-Wave JS maintainers may use AI tools for code review, issue triage, reporting, and other project management tasks. These tools may comment on pull requests or issues. Their output can be wrong.

Treat an AI-generated comment like any other review comment. If you believe it is incorrect, say so and give a brief explanation. Maintainers always have the final say. Ask a maintainer if you are unsure.

## Enforcement

We will close contributions that do not follow this policy. Repeated violations may result in the contributor being blocked from Z-Wave JS projects. If you believe we closed your contribution in error, contact a maintainer to discuss it.

This policy is adapted from the [Open Home Foundation AI policy](https://developers.home-assistant.io/docs/ai_policy/).
